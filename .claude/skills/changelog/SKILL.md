# Changelog

- Add entries under `## [Unreleased]` in `CHANGELOG.md`, grouped as `### Added`, `### Changed`, `### Fixed`, `### Removed` or `### Security`.
- Write one line per meaningful change, from the reader's point of view, e.g. "Added Corella barangay directory with 2024 PSA populations."
- Skip pure refactors, formatting and test-only changes unless they affect contributors.
- On release, rename `[Unreleased]` to `## [x.y.z] - YYYY-MM-DD` and start a fresh `[Unreleased]` section.
